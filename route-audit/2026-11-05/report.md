# FlClash 全部订阅实测报告

测试时段：2026-11-05 21:47–22:00（Asia/Shanghai）。来源为本机保存的订阅快照，未刷新订阅，也未切换 FlClash 当前节点。

共清点 32 份保存配置（数据库中 31 个订阅来源、1 个本地配置；其中一份订阅文件为空）。解析得到 998 条节点记录（包含余额、到期、联系信息等占位记录），326 个服务器地址；310 个地址有 IPv4，去重得到 200 个 IPv4。

## 结论

- 找到 **27 条本次可用且去程观察到 AS9929 的节点**，分属 Muacloud、Speedy、星河 583、掌中世界 4 个机场，使用 3 个不同入口 IP。
- **没有任何节点取得双向 CN2 GIA / 9929 / CMIN2 的完整证据**：本机只能直接测本机→入口的去程，缺少服务商侧向本机的回程 traceroute。
- 200 条入口路径中没有观察到 AS4809（CN2）或 AS58807（CMIN2）。这表示本次可见去程没有证实它们，不表示所有节点的隐藏中转段、回程均不存在这些线路。
- AS10099-only 的结果单独列出，未冒充 AS9929。AS58453 也不能代替 AS58807 当作 CMIN2。

## 方法和覆盖

- 通过读取全部 YAML 与 SQLite 的 ID/机场名对应，覆盖当前未启用的订阅；未导出密码、UUID 或订阅 token。
- 在 WLAN ifIndex 16、网关 192.168.2.1 上临时添加 /32 路由绕过 TUN，保留已有路由；结束后删除本次新增路由。
- 对 200 个 IPv4 各做一次 TTL 1–36 的 ICMP 去程探测，每跳超时 400ms；139 个目标返回终点回应，61 个没有完整终点回应。少量占位地址也计入覆盖统计，不当成可用服务。
- 对非 UDP-only 节点映射得到的 997 个不同 IP:TCP-port 做两次建连，825 个至少成功一次。TCP 开放不等于代理可用。
- 对 8 个出现 AS9929/AS10099 的入口，使用隔离的 Mihomo 核心、原订阅协议与认证参数，测试 91 个不同配置/入口组合，28 个完成 HTTPS generate_204 探测（其中 27 个有去程9929证据）。这一步同时测试了相关 Hysteria2 UDP 节点；失败只表示本次6秒窗口内未通过，并不证明永久失效。
- 三个 AS9929 入口额外各做两轮复测，共每入口三轮；每轮都观察到 AS9929。相应 TCP 端口另做五次高精度建连。
- 表中 HTTP 探测时间包含代理协议握手、转发、目标 HTTPS 与 HTTP 交互，**不是 ping RTT**；单次网站探测也不是吞吐量/长期稳定性测试。
